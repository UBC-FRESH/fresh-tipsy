fresh-tipsy
===========

A public, tested Python package for reading TIPSY and FAN$IER data tables, exposing growth, product-recovery, and economics workflows, and preserving the provenance of every value. It is a reimplementation and interoperability layer, not a claim of authorship over BC government models or data.

This site is the RTFM surface for the project. Agents read the relevant page before
they act, and cite it in their reports. Start with the repository's ``AGENTS.md`` and
``ROADMAP.md``, and add guides, reference contracts, and agent protocols here as the
project grows.
